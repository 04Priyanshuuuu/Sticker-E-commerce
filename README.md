# Sticke – Sticker & Poster E-Commerce Platform

Sticke is a full stack e-commerce platform built for selling stickers and posters online.

Live Website: https://sticke.vercel.app

## Features

- User Authentication (JWT)
- Login / Signup
- Browse stickers and posters
- Add to Cart functionality
- Persistent cart after login
- Checkout only for authenticated users
- Account management
- Contact Us section using EmailJS
- Image storage with Cloudinary
- REST API using Django REST Framework
- Fully deployed application

## Tech Stack

Frontend:
- Next.js
- React.js
- TypeScript
- Tailwind CSS
- HTML
- CSS
- JavaScript

Backend:
- Python
- Django
- Django REST Framework
- JWT Authentication

Database:
- PostgreSQL (Neon DB)

Services & Deployment:
- Cloudinary
- EmailJS
- Vercel
- Render
- Git & GitHub

## Deployment

Frontend: Vercel

Backend: Render

## Architecture

Frontend (Next.js)
        ↓
REST API (Django + DRF)
        ↓
PostgreSQL (Neon)

Cloudinary → Product Images
EmailJS → Contact Form
